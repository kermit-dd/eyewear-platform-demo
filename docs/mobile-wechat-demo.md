# 手机与微信 H5 Demo

## 局域网打开

1. 让电脑和手机连接同一个 Wi‑Fi。
2. 在项目目录执行 `npm run dev:lan`。
3. 查询电脑局域网 IP。macOS 可以在“系统设置 → 网络”中查看当前 Wi‑Fi 地址。
4. 在手机微信聊天窗口中打开 `http://电脑局域网IP:4174`。

当前电脑的局域网地址是 `192.168.3.38` 时，对应入口为：

```text
http://192.168.3.38:4174
```

局域网入口适合快速验证商品浏览、镜框筛选、尺寸详情、对比和购买意向表单。手机和电脑不在同一个 Wi‑Fi、电脑防火墙拦截或局域网隔离时，这个地址无法访问。

## 微信内试戴

浏览器摄像头接口要求安全上下文。微信内打开局域网 HTTP 地址时，商品页面可以访问，摄像头试戴会提示需要 HTTPS。

要在微信中测试真实试戴，需要把项目根目录部署到支持 HTTPS 的静态托管，例如腾讯云静态网站、CloudBase 静态托管或其他 HTTPS 域名，然后在微信中打开该 HTTPS 地址。项目是零依赖静态 H5，部署时直接上传项目根目录即可。

首次进入试戴页时需要允许微信使用摄像头，人脸模型会从 CDN 加载，建议使用稳定网络并保持正脸。

## 按尺寸试戴

试戴页右上角的“按尺寸试戴”进入第二种模式。可以输入验光单上的 PD，也可以切换到“标准参考卡片”。参考卡片默认宽度为 85.6 mm，把实体卡片放在脸旁，拖动参考框宽度与卡片重合，再开始测量。卡片不需要拍照上传，换算和推荐都在当前设备完成。
