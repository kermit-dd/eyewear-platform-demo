# Demo 验收清单

## 商品和尺寸

- [ ] 首页能看到商户名称和精选镜框。
- [ ] 商品列表能按风格筛选。
- [ ] 商品卡片显示价格和镜框总宽。
- [ ] 商品详情显示镜片宽、鼻梁宽、镜片高、镜腿长和镜框总宽。
- [ ] 对比页最多显示三款镜框。

## 试戴

- [ ] 点击“开始试戴”能进入试戴页。
- [ ] 浏览器允许摄像头后，画面能显示在试戴区域。
- [ ] 人脸模型加载成功时，镜框会随人脸移动。
- [ ] 拒绝摄像头权限时，页面显示可理解的提示。
- [ ] 可以切换镜框和调整镜框大小。
- [ ] CDN 或模型不可用时，页面不会崩溃。

## 配镜信息

- [ ] 可以上传图片或 PDF 格式的验光单并看到文件名。
- [ ] 可以选择散光有或无。
- [ ] 有散光时显示左右眼柱镜 C 和轴位 A。
- [ ] 左右眼都能填写球镜 S 和瞳距 PD。
- [ ] 手机号为空时不能提交。
- [ ] 刷新页面后，已填写的草稿仍可恢复。
- [ ] 提交后本地记录带有商户、镜框和验光参数。

## 运行命令

```bash
npm test
npm run build
npm run dev
```
