# 眼镜 H5 科技文艺视觉改版设计

## 意图

把当前偏暖、偏平的 Demo 改成更适合眼镜选购的“雾蓝科技 + 米白纸张”视觉系统。页面需要同时传达镜框材质的编辑感和尺寸试戴的仪器感，让用户先理解镜框，再进入试戴和校准。

## 目标

- 首页形成品牌入口、功能入口和精选镜框三个清晰层级。
- 挑镜框页面优先显示尺寸、风格、脸型标签和价格。
- 商品详情页让镜框图片、尺寸数据和试戴动作成为一个完整决策区。
- 直接试戴和按尺寸试戴显示实时状态、测量数据和镜框选择。
- 保持零依赖、移动端优先、GitHub Pages 子路径资源可用。

## 非目标

- 不改变租户、商品、验光、购买意向和摄像头计算逻辑。
- 不引入新的前端框架或动效依赖。
- 不把页面改成纯深色，也不使用高饱和霓虹色覆盖商品图片。

## 视觉系统

- 画布底色使用米白 `#f4f0e9`，卡片使用暖白 `#fffdf9`。
- 主文字使用墨蓝 `#182b38`，辅助文字使用灰蓝 `#63747c`。
- 科技强调使用雾蓝 `#9bbfc4`，操作强调使用铜橙 `#b87855`。
- 试戴舞台使用深墨蓝渐变，测量状态使用薄荷青和铜橙区分。
- 字体维持系统字体，标题采用较紧的字距与更克制的字号层级。
- 减少大面积圆角和胶囊按钮，保留小圆角卡片、细边框、网格线和细标签。

## 页面结构

### 首页

顶部保留品牌和对比入口。首屏改成带细网格和坐标线的品牌引导区，主标题强调“先量尺寸，再试戴”。三个入口分别对应挑镜框、直接试戴、按尺寸试戴。精选镜框使用两列编辑型卡片，图片区域和尺寸信息分离。

### 挑镜框

筛选条采用轻量分段标签。商品卡片减少阴影，增加材质标签、镜框总宽和适合脸型。选中的筛选项使用雾蓝底色，价格使用铜色作为唯一强对比文字。

### 商品详情

左侧或上方展示镜框，右侧或下方展示价格、尺寸建议和五项尺寸数据。试戴按钮成为首要动作，对比和咨询作为次级动作。

### 试戴

摄像头画面使用深色观测台。状态条显示 `LIVE`、人脸识别和模型状态。镜框选择器增加尺寸和适配结果，校准页保留 PD 与标准参考卡片两种方式。

## 验收

- 首页、列表、详情、直接试戴和按尺寸试戴都使用同一套新色板和边框语言。
- 页面在 320px 到 720px 宽度下不出现横向溢出。
- 现有 28 个测试继续通过，静态构建检查通过。
- GitHub Pages 和 HTTPS Demo 发布后，新入口和镜框图片都可加载。
