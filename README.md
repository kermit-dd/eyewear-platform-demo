# 丹阳眼镜样板店 H5 Demo

这是一个单商户眼镜选购与 AR 试戴 Demo，当前以零依赖静态 H5 方式运行。它包含商品筛选、镜框尺寸、镜框对比、摄像头试戴、购买意向和验光信息填写。

## 启动

项目只需要 Node.js 和 Python 3：

```bash
npm test
npm run build
npm run dev
```

启动后打开 `http://127.0.0.1:4173`。摄像头权限通常需要 localhost 或 HTTPS。首次进入试戴时，浏览器会请求摄像头权限，人脸模型会从 CDN 加载。

## 主要路径

- 首页：商户介绍和精选镜框
- 挑镜框：按风格筛选，查看尺寸和价格
- 商品详情：镜片宽、鼻梁宽、镜片高、镜腿长、镜框总宽
- 试戴：摄像头、人脸关键点、镜框切换和大小校准
- 对比：最多同时比较三款镜框
- 配镜需求：姓名、手机号、备注、验光单图片或 PDF、左右眼 S / PD / C / A 和散光开关

## 数据和租户

- 默认商户配置在 `src/config/tenant.js`。
- 演示商品在 `src/data/seed.js`。
- 每个 SKU 都带 `tenantId`，后续接入 CloudBase 或正式后端时可以迁移为租户表和商品表。
- 购买意向目前保存在浏览器 `localStorage`，没有上传人脸图像和验光单文件内容。

## AR 试戴说明

`src/features/tryon/tryon.js` 在浏览器内动态加载 MediaPipe Face Landmarker。摄像头拒绝、浏览器不支持或模型加载失败时，页面会显示状态提示，仍保留镜框选择和大小校准区域。

镜框素材默认使用 `assets/frames/` 下的透明 PNG，当前 Demo 已包含香槟金、玳瑁、晶透和酒红猫眼四种真实材质样式。渲染会按素材原始宽高比显示，避免镜框变形。后续可以替换为商户实拍商品图或 GLB，并在商品的 `tryOnAsset` 中设置比例和偏移校准。
